# Sprint 1 · 封面视觉单变量实验（预注册）

> **预注册**：判定规则在看到任何数据之前写死，事后不得修改。修改需另开 Sprint。

## 1. 实验设计
- **唯一自变量**：封面视觉风格
  - `Cover_A_Illustration`：上 55% 奶油底 + 倾斜三行大标题 + 胶囊副标题；下 45% 扁平插画（地标只能出现本帖目标地区）。
  - `Cover_B_Typography`：261021 升级版纯中文咨询封面（暖纸底 + 深红胶囊 + 三行黑体大标题 + 金色荧光条）。
- **冻结变量**：发布时间（12:30 / 20:00）、内页视觉系统、标题公式、正文长度区间、末页钩子形式、页数（同对 ±1 页）。
- **主指标**：发布后 T+48h 的封面点击率 = 观看 ÷ 曝光。
- **次指标（只记录，不参与判定）**：平均观看时长、收藏率、评论数。
- **已知局限**：同一对内两篇的话题不同（如 英国 vs 香港），话题效应与封面效应混在一起；通过 6 对中 A/B 先后顺序轮换来抵消，但样本小，结论只作方向参考。

## 3. 判定规则（写死）
6 对全部满 T+48h 后，运行 `python3 scripts/log_metrics.py evaluate Sprint1_Cover_Test`（数据用 `log_metrics.py add` 录入）：

1. **汇总检验**：A 组、B 组分别汇总曝光与观看，做双比例 z 检验。
2. **一致性**：逐对比较封面点击率，统计胜出方向。
3. **结论**：
   - p < 0.05 **且** 同一方向胜出 ≥ 4/6 对 → 判该封面胜出，写入 `config/brand.md` 作为新基线。
   - 其他情况 → **判"无显著差异"**，保留 `Cover_B_Typography`（基线 261021，历史 CTR 16.6%）为默认，Sprint 2 换测下一个变量。
4. **作废条件**：任一帖子 T+48h 曝光 < 200（疑似限流）→ 该对剔除，不补测。
