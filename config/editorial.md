# 大熙教育 · 内容编辑规则（变动频率：按季度）

> 数值型规则见 [`rules.json`](./rules.json)；事实数据见 [`../knowledge/facts_2026.md`](../knowledge/facts_2026.md)；当期实验见 [`../experiments/`](../experiments/)。

## 规则 1：窄切口（方案 B）
- 每篇只讲 **1 个国家/地区**，或 **2 个家长/学生真实二选一的对比地区**（如 港 vs 澳、英 vs 澳）。
- **禁止**一篇塞 3 个及以上地区；**禁止**两个地区挤在同一张内页。
- 窄 ≠ 小众：切口要窄在"地区 × 分数/预算段"，人群要宽（覆盖该分数/预算段的大多数人）。读者是**学生和家长**，不是顾问同行 —— 写"你该怎么选"，不写"顾问该怎么做"。

## 规则 2：页数不锁死，有多深写多深
页数由内容决定（常见 8–12 页，范围见 `rules.json`）。同一 A/B 对的两篇，页数差不超过 1 页。每篇必须具备四层骨架：

1. **认知纠偏 / 底层机制页**：为什么网上 3 年前的说法在 2026 年不成立。
2. **分路径深挖 + 劝退页**：每条路径独占整页，必须有 **2026 精确数字 + 隐藏暗坑 + ⚠️劝退谁**。
3. **同分不同命推演页**（至少 1 整页）：2 个分数/预算相近的具体学生或家庭，做出不同选择，一步步推演顾问的取舍逻辑。
4. **决策总览页 + 末页个性化查表钩子**。

## 规则 3：干货全给，钩子只留"千人千面"
- 方法论、校名、真实费用**全部讲透**，不得藏半截当诱饵。
- 末页只留 **一对一的多变量交叉查询**（如：陆本院校在各院内部 Tier List 的分差；31 省特控线 + 单科否决线折算）。

## 规则 4：事实只能来自本帖 `02_fact_sheet.md`
- 主笔不得使用 fact sheet 以外的排名、学费、政策数字。
- 机器闸门会检查：正文里每个 QS 排名都能在 fact sheet 中找到（`qs_rank_traceability`）。

## 规则 5：不重复
- 立项前查 `tracker/posts_master.csv` 和最近 14 天的帖子，避免同地区同分数段同角度重复。
- 禁止 PS Before/After 老套路重复出现。
